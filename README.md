### Sherwin Carlquist Project - Metadata Harvest

The Python code in this repository is used to download item metadata from the Portal to Texas History (https://texashistory.unt.edu/) at the University of North Texas. This metadata is used to link the records between archival items in the archives at the Botanical Research Institute of Texas (https://brit.org/) and the herbarium specimens at the California Botanic Garden (https://www.calbg.org/). While this code is project specific, it may be useful for others to use a similar approach.

The script uses the Sickle module (https://sickle.readthedocs.io/en/latest/) to harvest the metadata from the Portal to Texas History using OAI-PMH.
